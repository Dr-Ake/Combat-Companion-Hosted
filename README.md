# Combat Director Hosted Extension

This folder contains the static Owlbear Rodeo extension files for GitHub Pages or another static host.

Upload everything in this folder to a GitHub Pages repository, then use this kind of Owlbear install URL:

https://YOUR-GITHUB-NAME.github.io/YOUR-REPO-NAME/manifest.json

This folder is only the hosted UI. You still run the local companion on the GM computer:

D:\Combat Companion\Start Combat Director.bat

The hosted UI talks back to:

http://127.0.0.1:8765
